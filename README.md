# Museum der Wege

Ein unabhängiger digitaler Museumsprototyp von Salonformat (Isabella Kohout). Drei dokumentierte Objekte aus Wiener Sammlungen erzählen nicht nur, was sie sind, sondern was auf ihren Wegen geschah. Besucher:innen folgen den Geschichten durch Davor, Unterwegs und Heute.

Die gestalterische und inhaltliche Idee entstand unabhängig von den genannten Museen. Dieses Repository behauptet keine Zusammenarbeit oder institutionelle Autorisierung.

## Veröffentlichungsstand

Die interaktive Experience wird derzeit lokal entwickelt. Sie ist hier noch nicht als öffentlich spielbare Website veröffentlicht. Für mehrere Objektfotografien sind vor einer Veröffentlichung die Nutzungsrechte zu klären; deshalb werden diese Bilddateien nicht ohne Freigabe öffentlich hochgeladen.
